# Test Plan - TaskFlow

## Objetivo
Validar el correcto funcionamiento de la aplicación TaskFlow (API + UI).

## Alcance
- Gestión de tareas (CRUD)
- Validaciones de datos
- Integración API/UI

## Tipos de prueba
- Pruebas funcionales
- Pruebas negativas
- Pruebas de API
- Pruebas UI
- Pruebas de rendimiento básicas

## Herramientas
- Manual testing
- Pytest (API)
- Playwright o Cypress (UI)

## Estrategia
- Exploratory testing inicial
- Luego automatización de casos críticos
